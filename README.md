# 🥋 Kalai Sangamam Academy Management System

A modern Full Stack Academy Management System developed for **Kalai Sangamam Academy, Dindigul** to digitally manage academy operations, students, trainers, events, achievements, attendance, and more.

> 🚧 **Project Status:** Under Development

---

## 📖 About the Project

Kalai Sangamam Academy is a multi-disciplinary training academy offering professional coaching in:

- 🥋 Silambam
- 🥋 Karate
- 🧘 Yoga
- 🛼 Skating
- 🏹 Archery
- 📚 Hindi

This project aims to provide a complete digital solution for academy management through an intuitive web application for students, trainers, and administrators.

---

# 🎯 Objectives

- Digitize academy management
- Simplify student and trainer management
- Maintain attendance and fee records
- Showcase achievements and events
- Improve communication with students and parents
- Provide a secure Admin & Student Portal

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/kalai_sangamam_academy.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```
